# 游戏设计访谈

## 已确认

- 引擎与类型：Godot，俯视角 3D 场地赛车。
- 体验：街机偏技巧，容易上手，但需要减速入弯和控制油门；高速入弯会推头，土路更容易侧滑。
- 平台：手机，横屏。
- 控制：左侧左右转向按钮，右侧油门和刹车，默认自动回正。
- 镜头：斜俯视跟随，画面方向固定，向行驶方向稍微前瞻。
- 模式：单人与 AI 同场竞速，另有计时练习；首版不加入联网。
- 路面：同一条封闭赛道混合土路和柏油路，每圈经过两种路面。
- 规模：玩家加 5 辆 AI，每场约 3 分钟。
- 赛车能力：分别考虑极速、加速、低速转弯半径、抓地表现，不能仅以速度和操控总分代替。
- 转弯规则：高速时即使转向打满也可能转不过弯，需提前减速；低速转弯半径与高速抓地力分别影响驾驶。
- 平衡目标：允许车型拥有优势赛道，在不同布局和路面比例的赛道组上比较整体竞争力；每款车都有短板，不存在全能最强车。

## 待确认

- 红米 K40 实机性能测试条件与测量结果在交付验证时记录，不以开发机结果代替。

## 访谈状态

已完成五轮设计选择，用户已确认完整设计并授权开始代码实现；本文记录确认结果，不代表已实现。

## 第三轮确认

- 首版先交付 Android，以中端手机稳定 60 FPS 为性能目标；具体测试设备待定，尚未验证性能。
- 转向按钮相对车头：始终控制车辆自身的左转和右转，教学需说明车头朝下时的操作。
- 不增加独立手刹或漂移按钮；通过转向、油门和刹车控制自然侧滑，漂移没有额外加速奖励。
- 碰撞产生推挤和减速，没有车辆损坏；路外明显减速。
- 卡住时可长按复位，回到最近通过的合法检查点，比赛计时继续。
- 首版包含 4 款赛车、3 条混合路面赛道，分别偏高速、偏多弯、偏土路；全部开放。
- 美术暂定低多边形微缩赛车场，车身颜色鲜明，各类路面与路外区域清晰可辨；允许后续调整。

## 第四轮确认

### 车型与平衡

| 车型 | 优势 | 短板 |
| --- | --- | --- |
| 高速型 | 极速高 | 加速较慢、低速转弯半径大 |
| 灵巧型 | 加速快、低速转弯半径小 | 极速低 |
| 土路型 | 土路抓地和加速保持得更好 | 柏油路速度表现一般 |
| 均衡型 | 各项居中、容易掌握 | 各专项不占优 |

- 刹车能力纳入调校；属性具体数值由试跑确定。
- 初始平衡目标：相同驾驶水平下，三条赛道的归一化圈时平均值相差不超过约 3%。同时检查失误率和上手难度，不能仅靠 AI 圈时证明平衡。
- 该数值属于待验证目标，不是已达到的结果；归一化和采样方法在实现调校时明确。

### 比赛、AI 与记录

- 固定 3 圈，按总时长约 3 分钟设计赛道长度。
- 按顺序通过检查点才计圈；漏点必须返回补过或复位，不能通过路外抄近路跳过赛段。
- AI 不使用隐藏追赶加成，遵守相同车辆和路面规则。
- AI 有简单、普通、困难三档，通过刹车时机、路线和失误频率区分。
- 计时练习无 AI 干扰，本地保存每条赛道、每款车的最佳有效单圈和设置；复位过的圈不计纪录。
- 首版不包含幽灵车或在线排行榜。
- 切后台、来电或主动暂停时，整场比赛及计时立即暂停；返回后倒数 3 秒继续。
- 退出比赛不保存进行中的赛程。

## 第五轮确认：操作与交付

- 刹车至停稳，松开后再次按住刹车即可倒车；倒车限速，按油门先制动再前进，避免刹车时意外倒退。
- 玩家完成三圈后立即结算；已完赛车按完赛顺序排名，未完赛车按圈数和赛道进度排名。
- 结算显示名次、总时间、最佳单圈，提供重赛和返回选车。
- 交付 Godot 工程与 Android 调试 APK。
- 打包方式：GitHub Actions，使用 workflow_dispatch 手动触发并上传 APK 构建产物，不在提交或 PR 时自动打包。
- 完整流程包括选车、选赛道、难度选择、竞速与计时练习、暂停、结算及本地记录。
- 首版包含基础引擎声、碰撞声和路面反馈。
- 性能验收设备：红米 K40；目标 60 FPS，提供低／中两档画质。是否达标需实机测量，不能用开发机运行结果替代。

## 实现与验收边界

- 美术资产流程：使用内置 imagegen 创建赛车及地图元素参考图，再使用 Blender 建模；保留 `.blend` 源文件，并导出 Godot 可用的 `.glb`。参考图不作为三维模型的替代品。

- 车型参数、赛道几何、音效和触控布局的具体数值由实现与试玩调校确定，遵循上述已确认设计。
- 检查手机多点触控下转向与油门／刹车的组合输入、倒车切换、暂停恢复及复位流程。
- 检查顺序检查点、计圈、排名、完赛结算以及有效单圈保存。
- 对四款车在三条赛道进行圈时、失误率与上手难度比较；明确采样和归一化方法，报告目标与实际差距。
- Android APK 构建、安装试玩和红米 K40 性能分别验证；无法完成的验证需如实标注。
